Changes to optional features in Feature Management

This section outlines changes to features and feature updates controlled by Feature Management in version 29.0. Learn more in Optional features that are now mandatory.

Optional features now mandatory

  • Feature Update: 'Manual' flushing method without requiring pick
  • Feature Update: Enable generation of per Activity Code VAT Settlements in Italy. Applies to the Italy localization.
  • Feature Update: Provides functionality for having default values for financial reports
  • Feature Update: Use new communication texts for reminder terms
  • Feature: Disable SOAP web services on Microsoft UI pages
  • Feature: Introduce UI support for masking sensitive data.

New optional features

  • Feature Update: Accelerated Depreciation
  • Feature: New Document Report Experience (disabled by default)

Upgrade to 29.0

Online customers

  • New customers automatically get Business Central version 29.0.
  • Existing customers get a notification when update 29.0 is available. Admins can schedule update 29.0 to any date within the five-month update period, which ends in February 2027.

Learn more in Major updates for Business Central online.

On-premises customers

Deployments using version 24 or earlier must upgrade to version 25 before upgrading to version 29. Learn more in Upgrading to Dynamics 365 Business Central 2026 release wave 2.

The base application no longer includes several objects that were marked as obsolete in these earlier versions. Learn more in Important information and considerations when upgrading to Business Central version 29.

Existing release plans remain available for historical reference until further notice.
